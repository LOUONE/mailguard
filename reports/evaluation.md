# Evaluation report

Generated by `make evaluate`. Do not edit by hand. Metrics only, no message content.

Test split: 2,113 messages (622 ham, 285 spam, 1206 phishing) in 1,670 duplicate clusters. Brackets are 95% intervals from 1000 bootstrap replicates over clusters. Thresholds are fixed on validation ham, so the test FPR is measured, not chosen.

## What this test set can measure

- One ham message is 0.16% of test ham: a ham FPR is a count of a few messages, and its interval is wide.
- 1% target: 6 of 622 validation ham may be flagged when the threshold is set. Showing a test FPR below 1% with 95% confidence takes about 300 test ham with none flagged (rule of three); the test set holds 622.
- 0.1% target: 0 of 622 validation ham may be flagged when the threshold is set. Showing a test FPR below 0.1% with 95% confidence takes about 3,000 test ham with none flagged (rule of three); the test set holds 622.
- So the 0.1% operating point is a stricter threshold, not a measured 0.1% FPR.
